# Archive File 1.4.1 — обработка больших XML

Дата выпуска: 23 октября 2026 года.

## Что исправлено

В 1.4.0 файл мог успешно скачаться, но не попасть в архив из-за оценки памяти перед DOM-разбором. На сервере пользователя это проявилось на XML около 24 МБ: в журнале указан размер скачанного файла и сообщение «Недостаточно memory_limit PHP для разбора XML».

1.4.1 читает XML последовательно через XMLReader. Полный документ и массив всех предложений больше не размещаются в DOM. Для разделения оболочка и предложения записываются во временные файлы на диске. Части собираются последовательно и повторно проверяются.

## Проверки

| Проверка | Результат |

Реальная исходная ссылка и данные пользователя не включены в тест.

## Как обновить

1. Скачать [archivefile-1.4.1-pl.transport.zip](../../packages/archivefile-1.4.1-pl.transport.zip).
2. В установщике пакетов MODX установить как обновление. Компонент не удалять.
3. Очистить кеш MODX, обновить менеджер Ctrl+F5.
4. Нажать принудительное скачивание проблемного источника.
5. Проверить новую запись журнала, число предложений, lastfile и части.
6. Проверить следующий запуск cron.

Настройки источников, три успешные копии, публичные адреса и команда cron сохраняются. Лишние старые копии удаляются только при ротации после успешной загрузки. Ошибочные попытки не вытесняют успешные файлы.

Пример команды cron:

```sh
/usr/bin/php7.4 /полный/путь/core/components/archivefile/cron.php
```

## Ограничения

- Нужны место для временных файлов и доступная для записи временная папка PHP.
- Память зависит от текущего XML-узла или предложения; очень большое отдельное предложение всё ещё может требовать больше памяти.
- Сохраняется лимит размера загрузки archivefile.max_size_mb, по умолчанию 50 МБ.
- Произвольные XPath, DTD и внешние сущности не разрешаются.
- Файловая система и SQL не образуют общую транзакцию при аварийном завершении процесса; подробности в [архитектуре](../ARCHITECTURE.md).
- Старые ошибки в журнале остаются историей. Проверять результат новой попытки после обновления.

Код и пакет уже находятся в репозитории. Эта страница описывает существующую сборку, а не отдельный GitHub Release.
