# Archive File 1.5.0

## Изменения

- Оформление по палитре штатной темы MODX Revolution 2.8.5: компактные таблицы, серо-голубые заголовки, зелёная основная кнопка, согласованные поля и сообщения.
- Font Awesome из менеджера, подсказки и доступные подписи действий.
- Выделение раскрытого источника и aria-expanded/aria-controls на кнопке настроек.
- Все стили ограничены #archivefile-app. Пункт меню с ID archivefile остаётся независимым.
- Готовая команда cron без кавычек для обычных путей и кнопка «Копировать команду».
- Сохранён потоковый XMLReader из 1.4.1, настройки XML, разделение, три успешные копии и журнал.

Это HTML-интерфейс внутри CMP, оформленный в стиле MODX; замены на ExtJS Grid/Form не выполнялось. Способ подключения страницы сохранён.

## Подтверждения

23 октября 2026 года пользователь подтвердил улучшенный интерфейс на сайте: «так на много лучше». Это подтверждение оформления, а не отчёт о повторной проверке всех функций и реального большого источника.

Локально пройдены PHP 7.4 lint, сервис, установка/обновление через xPDO с имитацией MODX/SQLite и jsdom. Проверены копирование команды без кавычек, раскрытие, выделение, доступные иконки, защита от конфликта ID меню, XML-preview и ссылки частей. Тест XML 26 128 078 байт с 8500 предложениями при memory_limit=32M также пройден.

Отдельное подтверждение загрузки проблемного большого источника на сервере ещё ожидается.

## Установка

[Скачать archivefile-1.5.0-pl.transport.zip](../../packages/archivefile-1.5.0-pl.transport.zip).

Установить как обновление без удаления компонента, очистить кеш MODX, выполнить Ctrl+F5. Настройки и архив сохраняются. Команда cron прежняя по смыслу: меняется только отображение и возможность копирования. Путь PHP и сайта берётся из текущей установки.

Проверить раскрытие источника, прокрутку, иконки, копирование cron, ручную загрузку и следующий ежедневный запуск.
