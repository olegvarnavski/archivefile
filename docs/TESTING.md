# Проверки и диагностика

## Автоматические проверки

`php tests/service.php`: три копии после шести загрузок, независимые архивы, namespaces XML, generation-date, подсчёт offer, сохранение предыдущих данных при ошибках сети/XML/публикации, временные файлы, ежедневный запуск, принудительная загрузка отключённого источника, блокировка параллельных действий, запрет DTD/неподходящих URL/внутренних IP, удаление источника и файлов.

`php tests/install.php`: размещение файлов, bootstrap, регистрация меню, пустая новая установка, обновление с сохранением настроек, отключение/повторная установка, отсутствие автоматического удаления первоначального источника. Использует xPDO vehicle и SQLite; не проверяет реальный MySQL и manager DOM.

`npm test`: список, раскрытие настроек и трёх копий, повторные загрузки и обновление таблицы, удаление, добавление. jsdom не воспроизводит все особенности ExtJS, менеджера MODX и кеша браузера.

## Ручная проверка перед выпуском

1. Установка и обновление на MODX 2.8.5-pl / PHP 7.4 / MySQL.
2. После обновления: меню, отсутствие ошибок Console, сохранение источников и истории.
3. Новый XML-источник: сохранить, скачать, проверить метаданные и открытие lastfile.
4. CSV/XLSX/PDF: скачать и проверить реальные байты.
5. Шесть ручных скачиваний: осталось три исторические копии.
6. Ошибка сети и некорректный XML: три прежние копии и lastfile сохранены.
7. Отключить расписание: cron пропускает, ручное обновление работает.
8. Раскрыть/закрыть несколько источников, сохранить настройки, загрузить подряд несколько раз.
9. Проверить прокрутку и вертикальное выравнивание на длинной странице.
10. Копирование и скачивание, включая постоянный адрес без PHP и query-параметров.
11. Удаление: отмена сохраняет данные, подтверждение удаляет источник и файлы.
12. Два одновременных скачивания: второе отклонено lock.

## При сбое интерфейса

Не выпускать очередное исправление только по тексту ошибки. Собрать:

- версия пакета, MODX, PHP сайта и CLI;
- полная ошибка F12 → Console со стеком и JS-файлом/строкой;
- статус и ответ запроса в Network (list/save/fetch);
- загруженная версия mgr.js и признаки старого кеша;
- соответствующая запись MODX error.log;
- шаги воспроизведения и работает ли пакет 1.1.4 в тех же условиях.

Ошибка `appendChild` означает передачу не-DOM значения, но без стека не указывает конкретный вызов. Сообщения deprecated modRestClient, easyblacklist и customurls сами по себе не доказывают связь с Archive File.

## Восстановление

Сохранить резервную копию. Пакет восстановления 1.1.4 подтверждён на сайте. После установки версий с большим номером повторная установка меньшей версии может зависеть от менеджера пакетов: при необходимости собрать отдельный выпуск восстановления с номером выше текущего, используя исходники рабочей версии. Не удалять компонент или таблицы для устранения ошибки интерфейса. Старые lastfile при возврате к реализации 1.1.4 остаются на диске, но не обновляются; исторические копии выдаются старым обработчиком.
