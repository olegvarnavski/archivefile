# Archive File: правила разработки

- MODX Revolution 2.8.5-pl, PHP 7.4. Не использовать синтаксис PHP 8+.
- Последняя подтверждённая пользователем версия — 1.4.0. В 1.4.1 исправлена обработка больших XML; локальные тесты пройдены, подтверждение на проблемном источнике ещё ожидается. 1.2.0 — проблемная историческая версия, 1.1.4 — пакет восстановления.
- Не менять схему подключения CMP или переписывать интерфейс без воспроизводимой причины. Сначала диагностировать проблему и получить стек браузера.
- Обновления никогда не удаляют источники, архивы и настройки. Удаление — только отдельное действие с подтверждением.
- Ошибки сети, XML и публикации lastfile сохраняют прежние копии. Ротация — последние три успешные загрузки.
- Контекст других проектов не переносить сюда. Не коммитить runtime.php, конфигурацию сайта, выгрузки, секреты или реальные URL с токенами.
- Перед выпуском: PHP 7.4 lint, сервис, установка/обновление, UI. Проверка с имитацией не означает успешную установку на живом MODX/MySQL.
- Каждый выпуск получает описание и transport.zip. Сохранять рабочий пакет восстановления.

- Для XML сохранять потоковую обработку XMLReader; не возвращать загрузку полного фида в DOM или строку. Тест `php tests/large-xml.php` обязателен при изменении XML-обработки.
- Подтверждение локального теста не записывать как подтверждение на сервере пользователя. Реальные URL источников и содержимое фидов в документацию и тесты не включать.
