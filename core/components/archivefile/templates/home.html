Запуск по расписанию

Добавьте эту команду в cron хостинга на ежедневный запуск в 03:00 по Москве. Время cron зависит от часового пояса хостинга.

PHP CLI: настройка archivefile.cron_php_path (по умолчанию /usr/bin/php7.4). Путь к cron.php определяется автоматически. Изменить PHP можно в системных настройках MODX.

Загрузка…

Требуются PHP 7.4+, cURL, XMLReader и PDO MySQL. Лимит файла по умолчанию — 50 МБ. Ошибка скачивания не удаляет предыдущие копии.
